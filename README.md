# WaHelper

برنامج أندرويد (Kotlin + Jetpack Compose) بفيتشرين فقط:

1. **الرسايل** — يسجّل إشعارات واتساب (نص/اسم المرسل/صورة مصغّرة لو موجودة) من غير ما يفتح الشات، فمفيش "ظهرت" بتتبعت لواتساب.
2. **الاستوريهات** — يتصفّح مجلد واتساب اللي بيحمّل فيه الاستوريهات تلقائيًا على التليفون، فتقدر تشوفها من غير ما تدخل على استوري حد من جوه واتساب نفسه.

## حدود مهمة لازم تعرفها
- الرسايل الصوتية والملفات: إشعار واتساب بياخد منه بس اسم المرسل والنوع (مثلاً "رسالة صوتية")، مش الصوت أو الملف نفسه. الملف الفعلي بيتحمّل بس لما تفتح الشات في واتساب.
- الاستوريهات: البرنامج بيعرض اللي واتساب نفسه حمّله بالفعل على التليفون (مجلد `.Statuses`)؛ واتساب بيمسح الملفات دي بعد ما الاستوري تنتهي (~24-48 ساعة)، فلو عايز تحتفظ بحاجة احفظها بدري.
- لازم تدّي صلاحية "الوصول للإشعارات" (Notification Access) من إعدادات الأندرويد، والبرنامج بياخدك عليها لوحده.
- لازم تختار مجلد واتساب مرة واحدة (`Android/media/com.whatsapp/WhatsApp/Media`) من خلال شاشة اختيار المجلدات.

## البناء
المشروع فيه GitHub Actions workflow (`.github/workflows/android.yml`) بيبني APK تلقائي (debug) عند أي push، وتقدر تنزّله من تبويب Actions → Artifacts.

للبناء محليًا: افتحه بـ Android Studio (Hedgehog أو أحدث) وشغّل `./gradlew assembleDebug` بعد ما تعمل `gradle wrapper` مرة، أو استخدم `gradle assembleDebug` لو عندك Gradle متثبت (الإصدار المطلوب 8.9+).

## الصلاحيات المستخدمة
- `BIND_NOTIFICATION_LISTENER_SERVICE`: لقراءة إشعارات واتساب فقط (مفيش أي وصول لحسابات أو سيرفرات تانية).
- Storage Access Framework (اختيار مجلد يدويًا): لقراءة ملفات الاستوريهات المحفوظة محليًا بالفعل.

البرنامج بيشتغل بالكامل على جهازك، مفيش أي اتصال بالإنترنت أو سيرفر خارجي، ومفيش أي تعامل مع حساب واتساب أو أجهزة ناس تانية.
